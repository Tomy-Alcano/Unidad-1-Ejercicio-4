# Unidad-1-Ejercicio-4
Programacion 3 Unidad 1 - Ejercicio 4
Ejercicio 4 — Formulario de preferencias del usuario
Este ejercicio incorpora tres nuevos componentes que todavía no combinaste en un formulario completo: JComboBox, JRadioButton y JCheckBox. Repasá el Capítulo 6 (subcapítulos 6.2 y 6.3) antes de comenzar.

Construí una ventana que permita al usuario registrar sus preferencias personales con los siguientes componentes:

Una etiqueta y un JComboBox que permita seleccionar el país de residencia, con al menos 5 opciones
Una etiqueta y dos JRadioButton para seleccionar el género (las opciones son: Femenino y Masculino). Asegurate de que ambos estén correctamente agrupados para que solo se pueda seleccionar uno a la vez
Un JCheckBox con el texto "Acepto los términos y condiciones"
Un botón con el texto "Confirmar preferencias"
💡 Tip: recordá que el ButtonGroup gestiona la lógica de exclusión entre los JRadioButton, pero no es un componente visual: cada botón debe agregarse al panel de forma individual.
